# Maker Studio Supporter

Supporter is an optional license for the Maker Studio desktop editor. It helps fund development and adds recognition in the app and on Discord.

## What Supporter includes

| Benefit | Where you see it |
| --- | --- |
| **Supporter title** | The Maker Studio window title and welcome screen. |
| **Supporter badge** | The welcome screen and the About dialog. |
| **Discord role and priority help** | Link your Discord account to get the Supporter role on the Maker Studio server. Supporters get priority when asking for help there. |
| **Discord Rich Presence badge** | Your Discord activity shows a Supporter badge when you use Maker Studio with Rich Presence enabled. |

### Tools and customization

Supporter includes the following features. You can also use them during the free trial.

| Feature | What you can do |
| --- | --- |
| **Project favorites** | Star projects on the welcome screen and drag them to reorder the list. Open them from Windows Start or the taskbar, the Linux app menu, or the macOS Dock. |
| **Welcome screen** | Choose a background image and adjust its dimming and blur. |
| **Window icon** | Choose a built-in icon or use your own image. |
| **Title bar color (Windows)** | Match the window title bar to your active theme. |
| **MCP server** | Connect Codex, Claude Code or another compatible local assistant so it can read and edit your project. The Supporter tab can copy a setup command or JSON configuration. |

Map and event editing are part of the editor. The Supporter title, badges and Discord role require a Supporter license.

## Get and activate a license

[Visit the Maker Studio store](https://store.toskan.es/products/maker-studio/)

1. In Maker Studio, open **Settings → Supporter**.
2. Choose **Buy lifetime license** to open checkout, or **Start 7-day free trial** to try the licensed features.
3. After checkout, copy the key from your email. Return to **Settings → Supporter**, paste it into **License key** and select **Activate**.

The Supporter tab shows the active license and which benefits it includes. To move your activation to another computer, use **Deactivate this computer** on the old one, then activate the same key on the new one.

## Set up the Discord benefits

After activating Supporter, open **Settings → Supporter → Discord**, choose **Link Discord account** and complete the authorization in your browser. Join the Maker Studio server to use the role and priority help. If you unlink the account, its Supporter role is removed and you can link another account.
