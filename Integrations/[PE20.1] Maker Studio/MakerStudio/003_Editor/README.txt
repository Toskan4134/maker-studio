Maker Studio — Editor
=====================

The editor application is NOT bundled with this plugin. Install it once, then the in-game
debug menu ("Maker Studio... > Open Maker Studio") launches it automatically from its default
install location (Windows / macOS / Linux). The app auto-updates itself afterwards.

Download / install:
  https://github.com/Toskan4134/maker-studio/releases/latest

  Windows ..... Maker.Studio_<version>_x64-setup.exe   (installs to %LOCALAPPDATA%\Maker Studio)
  macOS ....... Maker.Studio_<version>_<arch>.dmg       (drag to /Applications)
  Linux ....... maker-studio_<version>_amd64.deb         (or the .AppImage)

Portable use (optional)
-----------------------
Drop the executable in this folder as "maker-studio.exe" and the plugin launches that copy
instead — no installation needed.

This folder
-----------
  Mods/        Project-level JS mods bundled with this integration.
  (the editor also writes tile-editor-config.json and .project-stats.json here)
